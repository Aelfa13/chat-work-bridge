## Quality gates

1. `UPSTREAM_BASELINE_GATE`：`main` 必须精确等于 `upstream/main`，不得混入个人治理或业务提交。
2. `WINDOWS_KNOWN_BASELINE_GATE`：以 352/251/98/3 和 0 unexplained failures 作为可解释的 supplemental baseline。
3. `WINDOWS_PORT_REGRESSION_GATE`：后续 Windows port 不得新增 unexplained failures；known failures 不得无解释增加；新增目标功能必须有 targeted Windows validation；known failures 应逐步减少。

Windows baseline 不得被描述为 352/352 PASS，也不得把已知平台失败直接描述为业务 bug。
