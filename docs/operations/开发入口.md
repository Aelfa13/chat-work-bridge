## 当前项目事实

- 现有 Node.js / TypeScript 项目，提供本地 MCP STDIO package。
- Node.js 要求为 22+；本地构建使用 `npm run build`，测试使用 `npm test`。
- GitHub CI 已存在于 `.github/workflows/ci.yml`，发布事实记录在 `RELEASE_NOTES.md`。
- `main` 是 stable / upstream-sync baseline；`dev` 是个人持续集成开发线；`feature/*` / `fix/*` 为短期分支。
- `origin` 是个人 fork：`git@github.com:Aelfa13/chat-work-bridge.git`。
- `upstream` 是原项目：`git@github.com:wudy29/engineering-bridge.git`。
- Git writes 默认 `MANUAL`；本次 bootstrap 不提交、不推送。
- 当前没有真实 production runtime，不记录 production host、service、database、backup server、secret 或 deployment path。

## 每个任务开始前

1. 读取项目根目录 AGENTS.md。
2. 读取 docs/status/ 下最新状态报告。
3. 确认当前分支和工作区。
4. 确认本次任务属于开发、验证、发布还是生产维护。
5. 中大型任务开始前保留可恢复 checkpoint。

## 标准开发流

~~~text
需求
  ↓

  ↓

  ↓
validation（需要时，独立开发测试边界）
  ↓
review/checkpoint
  ↓
release candidate（需要时）
  ↓

~~~
