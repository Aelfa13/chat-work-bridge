## Windows failure classification evidence

本次 `npm test` 实测汇总为 352 tests / 251 pass / 98 fail / 3 skipped，退出码为 1。98 项失败全部有实际错误证据，分类和为 `58 + 37 + 3 = 98`：

| 类别 | 数量 | 代表性失败测试 | 失败机制 |
|---|---:|---|---|
| `WINDOWS_SPECIFIC_PATH_SEMANTICS` | 58 | `POSIX: a Windows-style codex.exe layout on PATH does not change the bare spawn`；`returns immediately and exposes queued/running without a result`；`loads an absent catalog as empty and round-trips registrations through the file` | Windows `path.isAbsolute`、`.exe` 搜索和 Git workspace boundary 使用 Windows 语义；测试中的 `/registered/root`、`/canonical/*` POSIX fixture 在 Windows 下被拒绝或解析不同。构成为 executor 2 + registered task 40 + registry 10 + catalog 6。 |
| `ENVIRONMENT_EOL_CONFIGURATION` | 37 | `submit_controlled_patch registers a submitted proposal...`；`applies a refined proposal after restart without rerunning generation`；`real Git validation uses a detached temporary worktree...` | Windows 工作树中的实际文件为 CRLF，相关断言要求 LF；属于 Windows Git working-tree EOL 配置差异。 |
| `PERMISSION_MODEL_SYMLINK` | 3 | `accepts a symlink alias that resolves to the same Git top-level`；`COMMIT fails closed when a pre-existing unrelated untracked symlink is replaced`；`bind rejects paths outside approved roots, prefix siblings, and symlink escapes` | Windows `symlinkSync` 实际返回 `EPERM`，属于符号链接权限模型差异。 |

本次未观察到超出上述三类的新失败类别；这些失败不构成 upstream 全部通过的证明，因此 `UPSTREAM_REGRESSION_STATUS` 保持 `NOT_PROVEN`。
