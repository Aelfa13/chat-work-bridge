# Decision 0001: Freeze the v0.1 scope

Status: Accepted for implementation planning

## Decision

The first public release will provide a small, local-first, read-only task bridge from an MCP client to Codex in pre-registered Git workspaces.

The public repository will be created independently and will not inherit the private prototype's Git history, machine-specific configuration, private probes, credential launchers, or private runtime management.

## Deferred

Target-workspace writes, multi-executor routing, subagents, quota routing, tray UI, dashboard, remote transport, accounts, teams, and cloud task management.
